Classic 10×10 Minesweeper grid with 20 randomly placed bombs; auto-reveal: clicking an empty cell automatically reveals all connected empty cells
Flag system to mark bombs
Win/loss detection with a game-over reveal of all bombs
Full mobile support: Tap to reveal a cell, Long-press to place/remove a flag
Responsive design: the board scales fluidly to fit any screen size
Custom font and color-coded numbers (1–8), just like the original Windows Minesweeper.

How to Play
Left-click / tap a cell to reveal it.
Right-click (desktop) or long-press (mobile) a cell to flag it as a suspected bomb.
Numbers indicate how many bombs are adjacent to that cell.
Flag all the bombs correctly to win; click on a bomb, and it's game over.
